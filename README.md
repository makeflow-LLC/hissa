# منصة حصة

مشروع Next.js بسيط بواجهة عربية RTL، يعرض الصفحة الرئيسية عبارة «منصة حصة» في المنتصف.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## البناء للإنتاج

```bash
npm run build
npm run start
```

## التقنيات

- [Next.js 15](https://nextjs.org) مع App Router
- React 19
- TypeScript
- دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL)

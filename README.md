# منصة حصة

مدرسة رقمية بواجهة عربية RTL مبنية بـ Next.js: دليل معلّمين مع بحث وفلترة، وبروفايل لكل معلّم فيه منهج من وحدات ودروس مسجّلة (فيديو وشرح وصور ومرفقات) مع تتبّع تقدّم الطالب، وحصص مباشرة قابلة للحجز.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## البناء للإنتاج

```bash
npm run build
npm run start
```

## التقنيات

- [Next.js 15](https://nextjs.org) مع App Router
- React 19
- TypeScript
- دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL)

# منصة حصة

منصة تعليمية بواجهة عربية RTL مبنية بـ Next.js: دليل معلّمين مع بحث وفلترة حسب المرحلة والمادة، وصفحة بروفايل لكل معلّم تعرض نبذته وحصصه المتاحة مع إمكانية الحجز.

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## البناء للإنتاج

```bash
npm run build
npm run start
```

## التقنيات

- [Next.js 15](https://nextjs.org) مع App Router
- React 19
- TypeScript
- دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL)
